# React UI Libraries (`library-ui`)

Eksplorasi integrasi dan perbandingan tiga pustaka komponen UI populer di ekosistem **React 19 + TypeScript + Vite**.

---

## Mulai Cepat

```bash
cd library-ui
bun install
bun run dev
```

---

## Urutan Materi Berurutan Abjad (A–Z)

| Folder (`A–Z`) | Topik Asli | Pintu Masuk | Fokus Integrasi |
| :--- | :--- | :--- | :--- |
| `daisy-ui` | DaisyUI | `src/daisy-ui/index.tsx` | Kelas komponen semantik di atas Tailwind CSS (`daisyui`) |
| `radix-themes` | Radix UI | `src/radix-themes/index.tsx` | Komponen bertema & aksesibel menggunakan `@radix-ui/themes` (`<Theme>`, `<Flex>`, `<Button>`) |
| `shadcn-ui` | Shadcn UI | `src/shadcn-ui/index.tsx` | Komponen primitif aksesibel milik sendiri yang dikustomisasi dengan utilitas Tailwind CSS |
