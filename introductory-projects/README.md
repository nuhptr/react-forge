# Introductory Projects (`introductory-projects`)

Sepuluh proyek mini latihan dasar **React 19 + TypeScript + Tailwind CSS v4** untuk memantapkan penguasaan state, event, form, dan pemanggilan API.

---

## Mulai Cepat

```bash
cd introductory-projects
bun install
bun run dev
```

Pilih proyek langsung lewat dropdown/kartu di halaman — tidak perlu menyunting [`src/App.tsx`](./src/App.tsx). Daftar proyek ada di [`src/demos.ts`](./src/demos.ts), UI pemilih di [`src/components/module-picker.tsx`](./src/components/module-picker.tsx).

---
