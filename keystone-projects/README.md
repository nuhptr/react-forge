# React TypeScript Projects (`keystone-projects`)

Empat proyek aplikasi tingkat menengah-lanjut menggunakan **React 19**, **TypeScript** ketat, **Context API**, dan **Tailwind CSS v4**.

---

## Mulai Cepat

```bash
cd keystone-projects
bun install
bun run dev
```

---

## Daftar Proyek Berurutan Abjad (A–Z)

| Folder (`A–Z`) | Proyek Asli | Pintu Masuk | Fokus Arsitektur |
| :--- | :--- | :--- | :--- |
| `client-table-filtering` | Simple Filteration | `src/client-table-filtering/index.tsx` | Tabel dasbor klien dengan pengurutan kolom, filter multi-kolom, status, & paginasi |
